# Retro Admin App

Aplicación web construida con React + Vite que emula un entorno retro pixelado para gestionar usuarios y productos. Está pensada para dos tipos de roles: administrador y vendedor, e incluye autenticación, vistas protegidas y operaciones CRUD.

## Tecnologías utilizadas

- React + Vite
- TypeScript
- CSS estilo retro/pixelado
- Clean Architecture
- React Router DOM
- LocalStorage para persistencia temporal
- Vitest + Testing Library

## Requisitos

- Node.js v21.7.1
- pnpm (opcional, también puedes usar npm)
